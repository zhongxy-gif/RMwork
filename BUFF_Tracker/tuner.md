# tuner.py 脚本介绍

## 用途

`/home/zhongxiangyu/BUFF_Tracker/tuner.py` 是一个**专门用于调节HSV颜色参数**的工具脚本，它**不是**用于标注的。这个脚本的主要目的是：

- **离线调节HSV参数**：在运行主检测程序前，先找到合适的颜色阈值
- **实时预览效果**：可以同时看到原始视频和二值化处理后的图像
- **快速验证参数**：无需经过完整的检测流程，直接查看颜色分割效果

## 与主程序的区别

| 脚本 | 用途 | 显示内容 | 是否需要标注 |
|------|------|----------|--------------|
| `tuner.py` | **HSV参数调节专用** | 原始视频 + 二值化图像 | ❌ 无需标注 |
| `main.cpp` | **完整检测流程** | 检测结果（R框 + 扇叶框） | ✅ 需要标注 |

## 使用方法

```bash
cd /home/zhongxiangyu/BUFF_Tracker
python3 tuner.py /home/zhongxiangyu/BUFF_Tracker/能量机关视频.mp4
```

## 操作说明

1. **窗口布局**：
   - `HSV_Tuner`：调节面板，包含 H/S/V 的最小最大值滑块
   - `Original`：显示原始视频
   - `Mask_Dilated`：显示二值化处理后的图像

2. **快捷键**：
   - `空格键`：暂停/继续播放
   - `q` 或 `ESC`：退出程序

3. **参数说明**：
   - `H Min/Max`：色相范围（0-180），红色通常在 0-10 或 160-180
   - `S Min/Max`：饱和度范围（0-255），排除灰色背景
   - `V Min/Max`：亮度范围（0-255），排除过暗过亮区域
   - `Morph_K`：形态学核大小（1-20），用于去噪

## 工作流程

1. 调节滑块观察 `Mask_Dilated` 窗口
2. 目标是让目标物体（如红色扇叶）呈现白色，背景呈现黑色
3. 找到满意参数后，按 `q` 或 `ESC` 退出
4. 退出时选择 `y` 保存参数到 `hsv_params.json` 文件
5. 参数文件包含：
   ```json
   {
       "h_min": 4,
       "h_max": 30,
       "s_min": 98,
       "s_max": 255,
       "v_min": 169,
       "v_max": 255,
       "kernel_size": 8
   }
   ```

## 推荐工作流

1. 先用 `tuner.py` 调好HSV参数并保存
2. 查看 `hsv_params.json` 获取参数值
3. 根据需要修改 `src/main.cpp` 中的默认参数
4. 如果需要微调，可在主程序运行时动态调节HSV_Tuner窗口
